# Archer Mobile

Independent React Native client built with Expo. The app includes landing, login, and registration screens plus API-backed marketplace screens for job discovery and posting, proposals, and conversations. Admin workflows and the release platform decision remain open in the product spec.

## Local setup

```sh
npm install
cp .env.example .env
npm start
```

The API base URL defaults by platform: the iOS simulator uses `http://localhost:4000/api`, and the Android emulator uses `http://10.0.2.2:4000/api`. A configured `localhost` or `127.0.0.1` URL is also remapped to `10.0.2.2` on Android, so the same local `.env` works in both simulators. Set `EXPO_PUBLIC_API_URL` to a full URL ending in `/api` to override the default. For a physical device, use the development machine's LAN IP. Start the API separately and apply its migrations first; see the [Archer API setup guide](https://github.com/tinehtunhlaing/Archer-api#local-setup).

## API adapter

`src/api.ts` mirrors the JSON envelope and routes in `api/src/routes/`. After sign-in, the mobile app loads the current profile and conversations. The Profile tab shows and edits the user's display name, headline, location, bio, and skills through the API. Freelancers see searchable open jobs and their proposals; clients see their own jobs, including closed jobs, and can create or close a job, review proposals, and reject pending proposals. Both roles can read and send conversation messages. Protected calls receive a bearer token explicitly. The token is held in memory and clears when the app restarts. Amounts and bids remain decimal strings paired with `USD` or `MMK`; no conversion is performed.

The server localizes error messages from the `Accept-Language` header. Pass `en` or `my` to API functions; the default is English. User-authored content is returned unchanged. Job listings and inbox content are loaded from the API; the app shows loading, empty, and error states instead of sample data.

## Commands

- `npm start` — start Expo development server
- `npm run android` — launch on an Android emulator
- `npm run ios` — launch on an iOS simulator
- `npm run typecheck` — check TypeScript

Expo SDK 58 targets React Native 0.88 and React 19.3.0. Native iOS/Android project directories are generated by Expo when needed.
